A free, 100% client-side web utility to detect Docker Compose host port clashes, home LAN CIDR subnet overlaps, and explore standard ports for 120+ self-hosted applications with 1-click collision auto-remapping.

---

## ⚡ Features

- **Docker Compose Parser**: Paste any compose file and instantly see all container port mappings.
- **Collision Detector**: Flags duplicate host bindings in real-time.
- **1-Click Auto Remapper**: Automatically allocates alternative clean host ports and produces clean YAML.
- **Standard Port Catalog**: Built-in reference for Home Assistant, Plex, AdGuard, Nextcloud, Uptime Kuma, and 100+ others.
- **Subnet Watchdog**: Verifies Docker bridge networks against home LAN subnets (e.g. `192.168.1.0/24`) to prevent IP pool exhaustion.
- **Zero Tracking**: Runs entirely in the user's browser with no server storage.
